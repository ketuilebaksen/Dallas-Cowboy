And then this video produces the single best sentence about play design I’ve been handed in a month.

The chance to throw comes before everybody in the building knows Dak has to throw.

Think about what that means, because it’s a complete philosophy in fourteen words.

A pass on second and manageable is a different object from a pass on third and nine. On second and manageable the defense must still honour the run, so a safety takes a step forward and a corner is left alone. On third and nine the run has been removed from the equation, so every defender can play the pass, and the same throw to the same man against the same coverage is now a much harder throw.

So the value of a pass is highest when it is optional.

Which means a team that only throws when it has to has arranged for all of its throws to be the hard kind. And a two-point-four-yards-a-carry run game guarantees that, because two point four a carry turns every first down into a third and long.
