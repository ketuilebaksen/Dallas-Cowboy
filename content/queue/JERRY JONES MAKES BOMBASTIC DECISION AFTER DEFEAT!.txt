And that is the whole of the lesson, so let me state it as plainly as I can.

You cannot predict a result. You can predict the arithmetic.

If somebody gives you an extreme average over a handful of attempts, you do not know what happened, but you do know the two things that could have happened, and you can work out in advance what each one implies. Then when the detail arrives you have a check rather than a surprise.

And the football conclusion matters too, because it’s the opposite of the one everybody drew. Dallas did not get run over. Dallas gave up two explosive runs and held a backup running back to a bit over five a carry on everything else.

Now the offense, because today’s video puts the blame somewhere almost nobody has put it and I think it’s largely right.

The criticism is that Dallas’s offense never gave the defense any help. It couldn’t sustain drives, couldn’t control the clock, and fell into predictable patterns. And the specific charge is repeated inside runs and halfback draws that weren’t producing.

Let me take the halfback draw seriously for a second, because it’s the detail that tells you something.

A draw is a run disguised as a pass. The line sets as if to protect, the quarterback drops as if to throw, and the ball goes to the back late, into the space the pass rushers have vacated by running upfield.

So a draw is a counterpunch. It beats a defense that is attacking, because it uses the defense’s own forward momentum against it. It needs the defense to be throwing a punch.

Which means a draw against a defense that is sitting on the run is close to the worst available call, because it is a slow-developing run into a front that isn’t going anywhere. The back receives the ball later and further behind the line than on any other run concept, and the blockers have declared pass, which means nobody is driving anybody off the ball.

So if Dallas was repeatedly calling inside runs and draws against a defense expecting runs, that’s not bad luck. It’s a concept being used in the one situation it was not designed for.

And it explains the number I’ve been carrying for three days, which is twenty-four carries for fifty-six yards with no run by a running back longer than six. Two point three a carry with a hard ceiling is exactly what you’d expect from slow-developing runs into a prepared front.
